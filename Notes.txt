Main File
    main.py
    Entry point. Runs the lecture example (5 processes, 3 resource types) in the
    console: state, safety algorithm trace, then a resource request by P1.

    Run from inside src/:   python main.py

Banker logic File
    banker_logic.py
    File structure (imports flow downward):
        vector_utils.py   ->  vector helpers
        banker_models.py  ->  result containers + BankerError
        banker_logic.py   ->  BankersAlgorithm  (this file)
        banker_format.py  ->  plain-text output (console / test evidence)
        banker_gui.py     ->  Tkinter GUI (uses banker_logic)

    Formulas:
        Need      = Max - Allocation
        Available = Total - (column sums of Allocation)
        Safety:   Work = Available, Finish[i] = False find unfinished i with Need[i] <= Work; Work += Allocation[i]; repeat
        Request:  Request <= Need -> Request <= Available -> tentative state -> safety check -> GRANT / WAIT

Banker format File
    banker_format.py
    Plain-text output of the Banker's Algorithm results (console demo, README,
    test evidence). The GUI can ignore this file and read the result objects directly.
    The demo run lives in main.py.

Banker model File
    banker_models.py
    Result containers (what the GUI displays) and the custom error.
    Depends only on vector_utils.

Vector utils File
    vector_utils.py
    Small vector helpers used by the Banker's Algorithm backend.
    No dependencies on other project files.
